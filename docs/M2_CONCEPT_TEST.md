# M2 concept test - scheda operativa

Campione: 5-8 adulti generalisti, non soltanto praticanti yoga o meditazione.

## Script

1. Mostrare Home per 5 secondi senza spiegazioni.
2. Chiedere: “What does this app offer?”
3. Chiedere di avviare il contenuto disponibile.
4. Chiedere cosa significano le altre tre card.
5. Far esplorare timer, `Adjust sound` e `About the sound`.
6. Raccogliere valutazione 1-5 su chiarezza ed estetica.
7. Chiedere se qualcosa sembra promettere un trattamento medico.
